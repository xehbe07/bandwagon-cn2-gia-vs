## CN2 GIA 是线路等级，也是香港东京套餐的名字

理解这个区别，得先知道电信手里有几条不同等级的国际线路，价格和晚高峰表现差得很远：

- **AS4134（163 骨干网）**：最便宜、容量最大，也是晚高峰最挤的一条，普通云服务商基本都走它。
- **AS4809 CN2 GT（Global Transit）**：当初的定位是给 163 分流，但从 2019 年起在不少地区晚高峰已经和 163 差不多，多花的钱未必换来体验。
- **AS4809 CN2 GIA（Global Internet Access）**：真正的精品层，低延迟、低丢包，适合 VoIP、视频会议、联机游戏。代价是容量有限，每 Mbps 转接成本极高——搬瓦工自己的文档提到最高可到 $120/Mbps。也正因为容量金贵，这条网抗攻击能力很弱，被 DDoS 通常直接空路由处理。
- **AS23764 CTGNet**：电信较新的国际网络，实际表现和价格基本对标 CN2 GIA。

搬瓦工挂着「CN2 GIA」名头的专属套餐，机房固定在香港、东京、大阪、新加坡，买哪个城市就锁死在哪个城市，端口速度 1–1.5Gbps。香港到国内主要城市一般 30–60ms，东京大约 40–80ms。物理距离摆在那里，这些节点延迟确实低，但价格也上了一个台阶，而且对移动、联通用户没有专门的回程优化。

## GIA-E 的「E」指 E-Commerce，差异全在这里

E 代表 E-Commerce（电商系列），全部基于洛杉矶机房，主力节点是 DC6 CN2 GIA-E 和 DC9 CN2 GIA。洛杉矶到国内主要城市大约 110–180ms，比香港东京远，但它是搬瓦工线路选择最多的产品线。

它对大陆访问做的关键动作在回程：到大陆的流量按运营商分流，电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走精品网（AS10099）。DC9 目前把所有大陆方向流量都摊到这三条线上。这意味着如果你的访客、家人或同事里电信、联通、移动都有，GIA-E 能保证没人被留在烂路上——单线 GIA 套餐对电信用户是顶配，移动联通用户就享受不到同等待遇。

端口是另一处硬差别：GIA-E 从 2.5Gbps 起步，高配到 10Gbps，比亚洲 GIA 线的 1–1.5Gbps 大一截。

还有一条容易忽略的规则：GIA-E 套餐买下后可以在十几个机房间**免费迁移**，包括 DC6、DC9、日本软银 JPOS_1、荷兰 EUNL_9（联通 9929 精品网）、圣何塞、纽约、加拿大的 CN2 GIA 节点，以及 DC2、DC4、DC8 这些常规机房，前提是目标机房有库存。换 IP 则要单独付费，$8 起。硬件方面，洛杉矶 DC9 的机器已经换上 AMD EPYC 加 NVMe RAID-10，单核跑分约为老款 E5 平台的两三倍。
